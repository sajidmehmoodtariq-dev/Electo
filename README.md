# Electo - E-Voting Platform

Welcome to the **Electo** repository! This project is a comprehensive, full-stack web application designed to facilitate secure and location-aware elections.

## 🚀 Key Features
- **Role-Based Access Control:** Dedicated dashboards for Admins, Election Officials, and Voters.
- **Location-Based Voting:** Ensures voters can only participate in elections matching their registered City or Province.
- **Real-Time Vote Tracking:** Instant vote allocation and interactive analytics via Recharts.
- **Secure Authentication:** JWT-based authentication with support for OAuth (Google & GitHub).
- **Profile Management:** Image uploads handled securely through Cloudinary.

## 🛠️ Technology Stack
### Frontend
- **React 19 & Vite:** For a fast, modern UI.
- **Tailwind CSS:** For responsive and beautiful styling.
- **Recharts:** For data visualization.

### Backend
- **Node.js & Express:** Robust RESTful API architecture.
- **MongoDB & Mongoose:** Flexible NoSQL database.
- **Nodemailer & Cloudinary:** For email notifications and asset management.

## 📦 Running the Project
1. Clone the repository.
2. Navigate to `/backend` and run `npm install`, then `npm run dev`.
3. Navigate to `/frontend` and run `npm install`, then `npm run dev`.
4. Ensure your `.env` variables (MongoDB URI, Cloudinary keys, JWT Secret) are configured.
